# StorySpinner 🎨📚🎬

> Your ideas, spun into a living storybook—text, video, and voice, instantly.

## 🏆 Alibaba Cloud Singapore Hackathon 2025 Submission

StorySpinner is an innovative app that transforms simple story prompts into fully realized multimedia narratives, leveraging Alibaba Cloud's AI solutions for text, video, and voice generation.

## 🌟 Features

- **Prompt-Based Story Generation**: Input basic story parameters (title, genre, character, setting, mood, theme) and watch AI spin them into a complete narrative
- **AI-Generated Videos**: Each story includes 3 automatically generated video scenes that visualize key moments
- **Text-to-Speech Narration**: Stories include voice narration for an immersive experience
- **Bauhaus-Inspired Design**: Distinctive visual aesthetic with primary colors and geometric elements
- **Responsive Interface**: Works seamlessly across mobile and desktop devices

## 🛠️ Technology Stack

- **Frontend**: Next.js 15, React 19, Tailwind CSS
- **AI Services**:
  - Text Generation: Alibaba Cloud Qwen Plus LLM
  - Video Generation: Alibaba Cloud EAS (Wan AI model)
  - Voice Synthesis: Eleven Labs API
- **State Management**: Zustand
- **Styling**: Tailwind CSS with shadcn/ui components
- **Animation**: Framer Motion

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- pnpm (recommended) or npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/agrimsingh/storyspinner.git
   cd storyspinner
   ```

2. Install dependencies:

   ```bash
   pnpm install
   ```

3. Add environment variables:
   Create a `.env.local` file with the following:

   ```
   QWEN_API_KEY=your_alibaba_cloud_qwen_api_key
   EAS_URL=your_alibaba_eas_url
   EAS_TOKEN=your_alibaba_eas_token
   ELEVENLABS_API_KEY=your_elevenlabs_api_key
   ```

4. Start the development server:
   ```bash
   pnpm dev
   ```

## 🧩 How It Works

1. **Story Creation**: Users fill out a simple form with story parameters
2. **AI Text Generation**: Qwen Plus LLM generates a three-act narrative based on user inputs
3. **Video Generation**: Each act is paired with a video generated by a T2V model
4. **Text-to-Speech**: Story text is converted to speech for a multimedia experience
5. **Presentation**: The final story is presented with text, videos, and audio narration

## 🎯 Alibaba Cloud Services Used

- **Qwen LLM**: For story generation (via Qwen Plus model on Model Studio)
- **Tongyi Wanxiang**: Creates thematic videos per act
